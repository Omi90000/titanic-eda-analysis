# 🚢 Titanic Dataset — Exploratory Data Analysis

## Overview
A complete EDA on the Titanic dataset revealing how gender 
and wealth determined survival.

## Key Findings
- 🔴 3rd class male survival: 13.5%
- 🟢 1st class female survival: 96.8%
- 👥 Female survival 4x higher than male
- 💰 Fare & Pclass strongest predictors

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps Covered
1. Data understanding
2. Missing value analysis
3. Distribution analysis
4. Categorical analysis
5. Outlier detection
6. Correlation analysis
